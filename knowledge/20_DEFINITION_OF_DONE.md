# Definition of Done

## Purpose
Standard criteria that must be met before code is merged.

## Requirements
1. Code follows `04_CODING_STANDARDS.md`.
2. `03_ENGINEERING_RULES.md` are completely respected.
3. Relevant tests added and passing.
4. Knowledge base and architecture documents updated if contracts change.
5. All automated checks (lint, format, security scan) pass.
6. Acceptance criteria met.
7. Verification loop implemented for automation tasks.

## Current Status
- Enforced on PR level.
